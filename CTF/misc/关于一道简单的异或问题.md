这道题是春秋杯冬季赛时做到的，虽然比较简单但还是记录一下

题目：简单异或

题目内容：ys~xdg/m@]mjkz@vl@z~lf>b

一开始直接让ai写了脚本爆破，发现没爆出来，于是根据已知优化了一下

```python
# 输入字符串
input_string = "ys~xdg/m@]mjkz@vl@z~lf>b"

# 已知输出的开头
known_output = "flag"

# 用于存储推测出来的异或密钥
key = []

# 根据已知的输出和输入的前几个字符推测密钥
for i in range(len(known_output)):
    key.append(ord(input_string[i]) ^ ord(known_output[i]))

# 输出推测出的密钥（这步是为了验证推测的密钥）
print("推测出的密钥（每个字符的异或结果）：", key)

# 对整个输入字符串进行异或
output_string = ''.join(chr(ord(c) ^ key[i % len(key)]) for i, c in enumerate(input_string))

# 输出解密后的结果
print("异或后的输出结果：", output_string)
```
